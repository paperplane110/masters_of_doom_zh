Doom 启示录目录

尾声

游戏产业走向成熟，Carmack 荣登传奇之位，Romero 回归本心，而 John 双雄的宿怨，最终在一辆无法发动的法拉利前画上句点。

从 John 双雄相识，到游戏产业走向成熟，花了十年的时间。 美国电子游戏销售额创下了 108 亿美元的纪录，再次超过了电影票房。 随着手机游戏这个价值数十亿美元的新兴市场崛起，游戏的销量也将超过音乐。

玩家们也在长大。 他们的平均年龄已经二十八岁，远不再是满脸痘痘的少年。 玩家构成的多样化，也反映了游戏题材的新版图：从棒球到桥牌，从古罗马到未来日本，从米老鼠到 David Bowie。 据估计，60% 的美国人——一亿四千五百万人——都在玩游戏，其中包括六千二百万女性，还有美国总统（他承认自己每天都要玩几局电脑纸牌）。 在日本、德国、韩国这样的国家，游戏早已成为国民消遣。

随着游戏占据主流，围绕第一人称射击游戏的一些震动开始平息。 参议员 Lieberman 称赞了游戏公司在告知家长关于成人内容方面所做的努力。 尽管政客们仍在持续推动立法管制暴力游戏，法院却发出了信号：它们驳回了那些指控 Columbine 与 Paducah 的青少年枪手是受《毁灭战士》影响的数百万美元诉讼。 “这是一场悲剧，”一名美国地区法官宣判道，“但这样的悲剧根本无法用理性解释，法院也不该假装可以。”

这一时期也印证了一个时代的落幕，对 Silicon Alamo（硅谷阿拉莫）的大家庭来说尤其如此。 达拉斯曾至少孕育过六家游戏公司，如今，它那些最有野心的初创企业——包括 Romero 的 Ion Storm 和 Mike Wilson 的 Gathering of Developers——纷纷关门大吉。 那个叛逆者能独立统治数十亿美元行业的黄金时代，似乎已经过去了。 但精神仍在。 如今连最大的公司都在模仿 id 的创新（比如在线对战、免费赠送试玩版、鼓励玩家修改游戏），只不过它们称之为“病毒式营销”。 而随着手机等新平台的出现，也许下一批伟大的玩家，正等着从沼泽中崛起。 这个世界，永远会为下一款伟大的游戏做好准备。

至于 id 公司，其重拾昔日经典的决策，结果喜忧参半。 id 开发的资料片《Quake III Team Arena》在口碑与商业上都令人失望，许多人认为，它不过是对《Unreal Tournament》成功的苍白回应。 id 出品（但未参与开发）的 Game Boy Advance 版《指挥官基恩》，遭遇了类似的冷遇。 然而，《Return to Castle Wolfenstein》却在口碑与商业上都大获成功，尽管这部作品与前作几乎毫无相似之处（除了桌上摆着的几顿火鸡大餐）。

这一时期，John Carmack 被推上了传奇的宝座。 他在图形编程上的创新，正是麻省理工学院《Technology Review》杂志所说的“电子游戏驱动计算技术演化”的原因之一。 而他的慈善事业——包括他持续在网上免费开源的那些源代码——更是无人能及。 在圣何塞一年一度的游戏开发者大会上，二十九岁的 Carmack 成为互动艺术与科学学院名人堂的第三位、也是最年轻的一位入选者——这相当于游戏行业的奥斯卡。 在播放了一段 Bill Gates 的录像祝贺（他开玩笑说：“我只想让你知道，我能写出比 John 更丝滑、更精炼的代码。”）之后，Carmack 走上台，接受了同行们起立鼓掌致意——其规格堪与该行业首位入选者、任天堂的宫本茂（Shigeru Miyamoto）当年所受的礼遇相媲美。正是宫本茂创造了《超级马里奥》——那个命运之夜，Carmack 在 Softdisk 的 PC 上复刻的，正是这款游戏。

许多玩家心中的疑问是：做完《Doom III》之后，Carmack 会不会就此告别游戏？ Carmack 自己也不确定。 靠着游戏与引擎授权的收入，他觉得自己这辈子已经花不完钱了，事实上，他也在频繁地向慈善机构捐款。 况且，在图形科学中浸淫多年之后，他对自己的技艺已经近乎达到一种禅意般的领悟。 洗澡时，他会看到墙上有几道光条，心想：嘿，那是头顶灯光经过水龙头反射形成的漫反射高光。 这种视角并没有把他从自然世界中剥离，反而让他更深地欣赏这个世界。 “这些东西在我看来既迷人又神奇，”他说，“我不必站在大峡谷，才能欣赏这个世界运转的方式——在我家浴室的灯光倒影里就能看到。”

他在一个新的学习源泉上投入得更深了：他的火箭。 每周六，他都会和他的火箭团队碰面——其中包括法拉利专家 Bob Norwood——一起鼓捣他所说的“垂直起降过氧化氢火箭飞行器”。 Carmack 打造了一台登月舱风格的飞行器，中间配了一个桶形座椅，供他或他的妻子 Anna 乘坐。 下一步：或许要挑战 1000 万美元的 X Prize——该奖项要求获奖者在十四天内把三个人送上轨道并返回两次。 认识 Carmack 的人，都觉得他大有希望。

与此同时，John Romero 则乐于把目光放回近处。 他和 Stevie Case 一起住在达拉斯乡间那座宽敞的大宅里，他决定，如他所说，回到自己的根：设计与编程游戏。 在几次尝试传统的发行合作之后，Romero、Stevie 和 Tom Hall——尽管《Anachronox》好评如潮——决定放弃制作野心勃勃的电脑游戏这条路，转而投身掌上电脑、手机和其他手持设备游戏的未知疆域。 作为第一位拥抱这一新领域的知名开发者，Romero 成了手机游戏的拉拉队长，正如他当年为 PC 游戏摇旗呐喊那样。

秉持着最初的愿景——小团队、短周期、做小游戏——Monkeystone 用了几个月就完成了他们的第一款作品《Hyperspace Delivery Boy》。 Tom 和 Romero 与另外三名开发者一起，在 Romero 的乡间别墅里忙到深夜，设计并编写了整款游戏——就像当年一样。 游戏让玩家扮演 Guy Carrington，一名星际快递员，他的工作就是“运送宇宙中最重要的包裹！” 有位评论者称《Hyperspace Delivery Boy》是少数几款值得购买的掌上电脑游戏之一。 下一部作品：也许会是新版《指挥官基恩》——多亏他们从 id 买到了授权。 Tom 很高兴能让他的孩子 Billy Blaze 回家。

对 Romero 来说，Monkeystone 的乐趣不只是新的开始，更是与过去的决裂。 三十四岁生日刚过不久，他效仿 Tom 的做法，剪掉了那丛他自 1991 年以来一直留着的著名长发，留下一个利落的短发——打理起来，就像他的新公司一样轻松。 从不肯浪费任何东西的 Romero，把那丛黑色长发包了起来，捐给了 Locks of Love——一个为患病和贫困儿童提供假发的非营利组织。 他那标志性的长发并非唯一要告别的东西。 如今生活在卡车与泥土路环绕的乡间，Romero 发现他那件曾经珍视的宝贝没什么用武之地了：那辆《毁灭战士》买来的法拉利。

他在前院里满怀深情地给这辆车拍下各种角度的照片，并把照片连同描述一起上传到了人气在线拍卖平台 eBay，标题是“残暴的奢华（Brutal Luxury）”。 他解释说，考虑到自己改装花了超过十万美元——从涡轮增压系统到定制引擎——六万五千美元的起拍价完全物有所值。 “这辆车发出的声音，简直惊人得具有毁灭性，”他写道，“行驶在街上，只要你踩下油门，就会发出印地赛车般的轰鸣……你只能放声大笑，它实在太酷了。” 他还承诺，“这将是你见过的最酷的法拉利 Testarossa。” 最终以八万两千五百美元把它开走的买家，对此深表赞同。

另一辆法拉利，将把 Romero 和 Carmack 重新带回彼此身边。 事情发生在 Mesquite 的一场 Quake III 锦标赛场外。 往年在这里，John 双雄几乎从不搭理对方。 但这一次不同了。 比赛已经打完。恩怨已经了结。 而一位朋友正需要帮助。 Carmack 在停车场里，发动机怎么也发动不起来。 他听到一阵轰鸣，抬头望向一辆亮黄色悍马的车灯。 Romero 从车上走下来，手里拿着搭电线。 有活儿要干了。
